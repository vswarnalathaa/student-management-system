# Student Management System

A console-based Student Management System built using Python.

## Features

- Add Student
- View All Students
- Search Student by ID
- Update Student Marks
- Delete Student
- Student Statistics
- Grade Calculation
- Data Persistence using JSON
- Input Validation
- Modular Code Structure

## Technologies Used

- Python
- JSON
- Git
- GitHub

## Project Structure

student-management-system/

├── main.py

├── student_func.py

├── calculations.py

├── validation.py

├── file_handler.py

├── statistic.py

├── data.json

└── README.md

## Statistics Available

- Total Students
- Average Percentage
- Top Student
- Lowest Student
- Grade Distribution

## How to Run

1. Clone repository

```bash
git clone <repository-url>
```

2. Navigate to project folder

```bash
cd student-management-system
```

3. Run application

```bash
python main.py
```
